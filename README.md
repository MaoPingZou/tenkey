# tenkey

在终端里练习数字键盲打的小程序。主键盘数字行和小键盘都能练，每个键的错误率和反应速度都会记下来，帮你找出最弱的那几个键。

- 只用 Python 标准库（`curses`），不用装任何依赖
- 练习页默认**禅模式**：屏幕上只有数字和一条淡淡的进度线，按 `Tab` 可切到详细模式（速度、准确率、虚拟键盘、指法提示）
- 有专项练习、弱项强化、实战数据、限时挑战等多种模式
- 成绩保存在本地，带键位热力图和历史记录

## 怎么玩

1. 运行 `python3 tenkey.py`，用 `j` / `k`（或方向键）移动、`Enter` 确认，或直接按数字键 `1`–`5` 选一个练习模式（新手先选 **1 基础练习**）。
2. 屏幕上会出现几组数字，**照着从左往右敲**。打对的变绿；打错时光标不动，改对后才能继续。
3. 敲下第一个键开始计时。组之间的空格不用按，程序会自动跳过。
4. 默认是禅模式，只显示要敲的数字。需要提示时按 `Tab` 切到详细模式：屏幕下方的虚拟键盘会**高亮下一个键**，并告诉你用哪根手指。再按 `Tab` 切回禅模式，选择会被记住。
5. 一轮打完会看到速度、准确率和本轮键位热力图，按 `Enter` 再来一轮。
6. 练过几轮后，可以试试 **3 弱项强化**：程序会专门多出你容易错、反应慢的键。

禅模式：

```text



      48213  90571  33820  61947  20538  77412

      59036  18264  40719  83652  26490  15873

      ──────────────·································


```

详细模式（按 `Tab` 切换）：

```text
 tenkey · 基础练习                         ESC 放弃 · Tab 禅模式

      48213  90571  33820  61947  20538  77412

      59036  18264  40719  83652  26490  15873

          速度  142 字/分    准确率  97.6%    进度 13/60

            1   2   3   4   5   6   7   8   9   0
                      下一个  2   ·   左手无名指
```

> 建议：**先求准，再求快**。准确率稳定在 95% 以上后，再逐步提速或加大组长度（`-s 6`）。

## 运行要求

- Python 3.8+
- macOS / Linux 终端（Windows 需先 `pip install windows-curses`）
- 终端窗口至少 50×22

## 安装与启动

```bash
git clone https://github.com/MaoPingZou/tenkey.git
cd tenkey
python3 tenkey.py
```

想在任何目录下用 `tenkey` 启动，可以加一个别名：

```bash
echo "alias tenkey='python3 $(pwd)/tenkey.py'" >> ~/.zshrc && source ~/.zshrc
```

## 练习模式

| 菜单键 | 模式 | 说明 |
|:---:|---|---|
| 1 | 基础练习 | 0-9 随机数字，默认 5 位一组、每轮 12 组 |
| 2 | 专项练习 | 按数字键挑出要练的键（比如 `4 5 6`），程序会记住你的选择 |
| 3 | 弱项强化 | 按历史错误率和反应时间出题，越弱的键出现得越多 |
| 4 | 实战数据 | 手机号、金额、日期、时间、IP、身份证、银行卡、验证码等 |
| 5 | 限时挑战 | 在限定时间内（默认 60 秒）尽量多打 |
| 6 | 统计数据 | 累计成绩、各模式最佳、每个键的次数／错误率／平均反应时间 |
| P | 键位提示 | 在「主键盘数字行」和「小键盘」两种布局之间切换 |

## 练习规则

- **敲下第一个键才开始计时**。组与组之间的空格会自动跳过，不用按空格。
- **按错时光标不前进**：当前字会闪红，并提示你按了什么、应该按什么。
- 颜色含义：🟩 一次打对　🟨 出过错后改对　⬜ 还没打到
- 每轮结束后显示：
  - 速度（字/分）、准确率、用时，并和本模式最佳、近 10 轮平均比较
  - 本轮键位热力图：绿＝全对，黄＝偶有失误，红＝错得多
  - 错得最多的键和反应最慢的键
  - 准确率不低于 90% 且超过历史最佳时，提示「新纪录」

### 指法提示

主键盘数字行：

| 键 | 1 | 2 | 3 | 4 5 | 6 7 | 8 | 9 | 0 |
|---|---|---|---|---|---|---|---|---|
| 手指 | 左小指 | 左无名指 | 左中指 | 左食指 | 右食指 | 右中指 | 右无名指 | 右小指 |

小键盘（右手）：`7 4 1` 用食指，`8 5 2` 用中指，`9 6 3 .` 用无名指，`0` 用拇指。

## 命令行参数

```text
python3 tenkey.py [-m MODE] [-s SIZE] [-n GROUPS] [-t TIME] [--pad] [--zen | --detail]

  -m, --mode    跳过菜单直接进入：basic / custom / weak / scene / timed / stats
  -s, --size    每组数字个数（默认 5，范围 1-20）
  -n, --groups  每轮组数（默认 12，范围 1-200）
  -t, --time    限时挑战秒数（默认 60，范围 5-3600）
  --pad         键位提示使用小键盘布局
  --zen         以禅模式进入练习：只显示数字（默认；练习中按 Tab 切换）
  --detail      以详细模式进入练习：显示速度、准确率、键盘和指法提示
```

示例：

```bash
python3 tenkey.py -m timed -t 30      # 30 秒限时挑战
python3 tenkey.py -m weak -s 6 -n 20  # 弱项强化，每组 6 位，共 20 组
python3 tenkey.py --pad               # 用小键盘布局提示
python3 tenkey.py -m basic --zen      # 直接以禅模式开始基础练习
```

## 快捷键

| 场景 | 按键 |
|---|---|
| 菜单 | `j` / `k`（或 `↑` `↓`）上下移动，`g` / `G` 跳到第一项 / 最后一项，`l` 或 `Enter` 确认；也可直接按菜单键 `1`–`6` / `P` / `Q` |
| 练习中 | `Tab` 切换禅模式 / 详细模式，`Esc` 放弃本轮（不记录成绩） |
| 成绩页 | `Enter` 再来一轮，`M` 返回菜单，`Q` 退出 |

## 数据存储

成绩保存在 `~/.tenkey/stats.json`。用环境变量 `TENKEY_HOME` 可以换目录：

```bash
TENKEY_HOME=~/Dropbox/tenkey python3 tenkey.py
```

删掉这个文件就能清空全部记录。

## 常见问题

**小键盘按了没反应？**
先确认 NumLock 已打开。部分终端在「应用键盘模式」下会把小键盘数字发成转义序列，程序已经能识别这种情况。如果还不行，请检查终端设置里的小键盘选项。

**颜色显示不对？**
请使用支持 256 色的终端（`TERM=xterm-256color`）。终端不支持颜色时，程序会改用反色、加粗、下划线来区分状态。
